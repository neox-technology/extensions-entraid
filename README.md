# Neox.Extensions.EntraId

Extensions Microsoft Entra ID.

## Installation

Prérequis : [.NET 10 SDK](https://dotnet.microsoft.com/download).

```bash
dotnet restore Neox.Extensions.EntraId.slnx
dotnet build Neox.Extensions.EntraId.slnx
```
